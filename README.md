# 🌸 Sofia Hagio | Portfólio 

> Um portfólio desenvolvido do zero para apresentar minha trajetória, habilidades e projetos de forma visual e interativa.

---

## 🌐 Acesse o portfólio online

🔗 https://sofiahagio.vercel.app/

---

## 💬 Seções do portfólio

* **Sobre mim**: apresentação, links e download do currículo
* **Skills**: habilidades técnicas separadas por categoria
* **Formação**: histórico educacional
* **Projetos**: trabalhos desenvolvidos, com links para repositório e site
* **Experiência**: experiência profissional
* **Contato**: canais de comunicação

---

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts (Playfair Display + Inconsolata)
* Bootstrap Icons + Devicon (ícones)
